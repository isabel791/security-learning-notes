# Pass-18 条件竞争 + 重命名

## 一、关卡说明

与 Pass-17 类似，但服务端会 **重命名** 文件（改为随机名 + 白名单后缀），所以不能直接访问固定路径，需要绕过重命名。

## 二、原理说明

```php
$ext = end(explode('.', $_FILES['upload_file']['name']));  // 取后缀
if (!in_array($ext, $white_list)) { unlink($tmp_file); }
$name = rand(1,10000) . '.' . $ext;                        // 随机名
move_uploaded_file($tmp_file, $upload_dir . $name);
```

攻击点： **临时文件在重命名之前，本身就存在于临时目录** 。

关键：`move_uploaded_file` 的临时文件路径是 `$tmp_file`，它在 PHP 接收上传时就已生成（系统临时目录），这个 **原始临时文件可以提前被访问到** 。

## 三、绕过步骤

1. 上传时的临时文件路径一般类似 `/tmp/phpXXXXXX`
2. 使用 **条件竞争 + 目录遍历** ：上传文件时文件名写为 `1.php`，但利用 `../` 构造访问路径
3. 更常见的做法是 **竞争临时文件** ：持续上传同时持续访问 `/tmp/php*` 路径（需要知道临时目录被映射到 Web）
4. 实际靶场通关思路：
   - 上传的内容为写马脚本，持续上传
   - 持续访问 `upload/xxx.php`（结合已知随机命名规则或目录可列举）
   - 抢先执行一次写入永久后门

## 四、验证

攻击结束后检查上传目录是否有新增可执行的 PHP 文件，蚁剑连接成功。

## 五、防御建议

1. 校验在移动之前完成
2. 设置 PHP 临时目录与 Web 目录隔离
3. 上传目录禁止执行脚本
