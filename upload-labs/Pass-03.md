# Pass-03 黑名单特殊后缀绕过

## 一、关卡说明

服务端改用 **黑名单** 方式校验扩展名，禁止 `.asp`、`.aspx`、`.php`、`.jsp`，但忽略了其他同样能被解析的扩展名。

## 二、源码分析

```php
$deny_ext = array('.asp','.aspx','.php','.jsp');
```

黑名单只列举了最常见的几种，没有覆盖 PHP 的其他可解析别名。

在 Apache + PHP 默认配置下，以下扩展名都会被当作 PHP 脚本解析：

- `.php3`
- `.php4`
- `.php5`
- `.phtml`
- `.phps`
- `.pht`

黑名单的天然缺陷就是 **永远列举不完** 。

## 三、绕过步骤

1. 将 webshell 后缀改为黑名单之外的别名，例如 `shell.php3`
2. 直接通过页面上传（不需要抓包）
3. 文件上传成功，路径为 `upload/shell.php3`
4. 浏览器访问该路径，PHP 代码被执行

如果 `.php3` 不被解析，按顺序尝试：`.php5` → `.phtml` → `.phps`

## 四、验证

访问 `http://靶场地址/upload/shell.php3`，PHP 代码正常执行，蚁剑连接成功。

## 五、防御建议

1. 应采用 **白名单** 而非黑名单校验扩展名
2. 若业务必须使用黑名单，需覆盖所有可解析后缀——但这本身就有隐患
3. 在 Web 服务器层禁止上传目录执行脚本，例如 Apache 配置 `php_admin_flag engine off`
