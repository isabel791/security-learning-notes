# Pass-01 前端 JS 校验绕过

## 一、关卡说明
上传一个 webshell（.php 文件），目标是上传成功并能在服务器执行。

## 二、前端验证代码分析
前端通过 JavaScript 对文件后缀进行白名单校验（只允许 .jpg/.png/.gif）。
由于验证在前端完成，可以被绕过。

## 三、绕过步骤
1. 方法一：浏览器禁用 JavaScript 后直接上传
2. 方法二：开启 Burp Suite 代理拦截，上传 .jpg 后在请求包中把文件名改为 .php 并放行

## 四、验证
用蚁剑连接上传后的 webshell 地址，成功执行命令。

## 五、防御建议
前端校验只能提升用户体验， **真正的校验必须放在服务端** ；服务端需校验文件扩展名、MIME 类型、文件内容三方面。
