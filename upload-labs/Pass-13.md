# Pass-13 文件头检测绕过（图片马）

## 一、关卡说明

服务端读取文件前两个字节判断类型，要求必须是 JPEG、PNG 或 GIF 的文件头。通过制作文件头合法的「图片马」绕过。

## 二、原理说明

常见文件头魔数：

| 类型 | 文件头（十六进制） |
|---|---|
| JPEG | FF D8 FF |
| PNG | 89 50 4E 47 |
| GIF | 47 49 46 38 |

服务端只检查这几个字节，不检查后面内容，所以在合法图片中追加 PHP 代码即可同时满足校验和执行。

## 三、绕过步骤

 **方法一：命令行合成** 

```bash
copy /b 1.jpg + shell.php shell.jpg
```

Windows 下 `copy /b` 以二进制方式拼接两个文件，`shell.jpg` 开头是 JPEG 头，后面是 PHP 代码。

 **方法二：编辑器手动合成** 

1. 用 010 Editor 或 Hex 编辑器打开 `1.jpg`
2. 滚动到文件末尾，粘贴 PHP 木马代码
3. 另存为 `shell.jpg`

 **上传并利用** 

1. 上传 `shell.jpg`（通过文件头校验）
2. 此关需要结合 **文件包含漏洞** （如 `?file=upload/shell.jpg`）才能执行
3. 或者配合 `.htaccess`（Pass-04 思路）让 `.jpg` 被解析

## 四、验证

若靶场需要包含执行，访问 `index.php?file=upload/shell.jpg`，代码执行；若能直接访问执行则直接连接。

## 五、防御建议

1. 不能只检查文件头，需结合 `getimagesize()`、二次渲染等更深检测
2. 上传目录禁止脚本执行
3. 图片文件应做二次处理（重新压缩、剥离元数据）
