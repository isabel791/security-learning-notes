# Pass-11 %00 截断（GET 方式）

## 一、关卡说明

服务端把用户提交的文件名与固定目录拼接后，使用 `move_uploaded_file()` 保存，但配合 `%00` 截断可控制最终路径。

## 二、原理说明

`%00` 是 URL 编码的空字符（NULL 字节），在 PHP 5.3.4 之前，字符串处理函数遇到 `\0` 会 **认为是字符串结束** 。

配合 `move_uploaded_file()` 的路径参数使用：

```php
$upload_file = $dir . $file_name . '.jpg';
```

如果 `$file_name` 中插入 `%00`，路径会在空字符处被截断，后面的 `.jpg` 被丢弃。

## 三、绕过步骤

1. 确认靶场 PHP 版本低于 5.3.4（高版本已修复）
2. 上传 `shell.php` 文件
3. 在 Burp 的 Proxy → Options 中开启  **URL 解码** ，或使用十六进制编辑器在文件名中插入 `00`
4. 文件名改成 `shell.php%00`（或 `shell.php.png` 中间插空字节）
5. 放行后服务端路径被截断为 `upload/shell.php`
6. 访问执行，但 **注意 Burp 可能自动二次编码** ，需要取消勾选

## 四、验证

成功执行则说明截断生效。此关需要 PHP 5.3.4 以下环境，当前新版本靶场一般无法通关，属于历史漏洞。

## 五、防御建议

1. PHP 5.3.4 起已修复空字符截断问题，保持 PHP 版本更新
2. 使用白名单校验
3. 服务端生成随机文件名
